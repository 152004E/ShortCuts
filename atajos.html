Mis atajos principales

AcciónAtajoDescripción
Abrir Visual Studio Code Meta + C script Abre VS Code en la carpeta activa de Dolphin (tu script open-code)
Abrir Archivos (Dolphin) Meta + E Abre el administrador de archivos
Abrir Consola (Ghostty) Ctrl + Alt + T Abre la terminal (Ghostty, el atajo global actualmente apunta a Ghostty, no a Konsole)
💡 Nota: La tecla Meta es la tecla de Windows / Super de tu teclado. El atajo de VS Code es Meta+C, no Ctrl+C (esa combinación se usa para copiar).
⚠️ Cuidado con Meta + Fn: si pulsas Meta + Fn (por ejemplo al intentar Alt+Fn+F4 y fallar la tecla), el firmware del portátil Lenovo desactiva la tecla Meta a nivel de hardware. Para reactivarla pulsa Fn + Meta de nuevo (es un interruptor, como un "Caps Lock" de la tecla Super). Si no funciona, reinicia el equipo.

⚠️ ¿Por qué pasa? Tu IdeaPad Slim 3 (Lenovo) trae un interruptor por firmware en el teclado: Fn + Super bloquea/desbloquea la tecla Meta (Windows) antes de que KDE siquiera la vea. No es un fallo de Arch ni de KDE. Lo activas sin querer cuando quieres hacer Alt+F4 pero tu dedo cae en la tecla Meta. La solución es siempre la misma: Fn + Meta la reactiva al instante.
