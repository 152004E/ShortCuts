# Index

## Mis atajos principales

| Acción | Atajo | Descripción |
| --- | --- | --- |
| Abrir Visual Studio Code | `Meta + C` **[script]** | Abre VS Code en la carpeta activa de Dolphin (script genérico open-editor) |
| Abrir Antigravity IDE | `Meta + A` **[script]** | Abre Antigravity en la carpeta activa de Dolphin (script genérico open-editor) |
| Abrir Archivos (Dolphin) | `Meta + E` | Abre el administrador de archivos |
| Abrir Consola (Ghostty) | `Ctrl + Alt + T` | Abre la terminal (Ghostty, el atajo global actualmente apunta a Ghostty, no a Konsole) |
| Abrir navegador (Brave) | `Meta + N` **[app]** | Abre el navegador Brave (atajo global → comando brave) |
| Abrir cámara (Kamoso) | `Meta + K` **[app]** | Abre la cámara web con Kamoso (atajo global → comando kamoso) |
| Abrir Configuración (Preferencias) | `Meta + I` **[app]** | Abre las Preferencias del Sistema (systemsettings) |

## Manejo de ventanas

| Acción | Atajo | Descripción |
| --- | --- | --- |
| Maximizar ventana | `Meta + PgUp` | Amplía la ventana a pantalla completa |
| Minimizar ventana | `Meta + PgDn` | Esconde la ventana a la barra de tareas |
| Restaurar ventana | `Meta + Retroceso` | Restaura una ventana minimizada |
| Cerrar ventana | `Meta + W` · `Alt + F4` | Cierra la ventana activa. |
| ⚠️ Desactiva la tecla Meta | `Meta + Fn` | No lo pulses por error: apaga la tecla Super por firmware |
| ✅ Reactiva la tecla Meta | `Fn + Meta` | Lo mismo pero al revés: vuelve a encenderla |
| Cambiar de ventana | `Alt + Tab` | Alterna entre ventanas abiertas |
| Mostrar escritorio | `Meta + D` | Minimiza todo / muestra el escritorio |
| Ventana a la izquierda / derecha | `Meta + ←` / `→` | Ajusta la ventana a media pantalla |
| Ajustar a esquina | `Meta + ←` y luego `↑` | Coloca la ventana en un cuarto de la pantalla |
| Cambiar escritorio virtual | `Ctrl + F1-F4` | Navega entre escritorios virtuales |
| Vista general (Overview) | `Meta + F` | Muestra todas las ventanas abiertas y escritorios virtuales |

## Atajos del sistema KDE

| Acción | Atajo | Descripción |
| --- | --- | --- |
| Menú de inicio | `Meta` | Abre el lanzador de aplicaciones |
| KRunner (buscador) | `Alt + Espacio` | Busca apps, archivos y ejecuta comandos |
| Bloquear pantalla | `Meta + L` | Bloquea la sesión (en Plasma 6 ya no es Ctrl+Alt+L) |
| Captura de pantalla | `ImpPantalla` | Abre Spectacle (captura completa) |
| Captura de área | `Meta + Shift + ImpPantalla` | Selecciona una zona de la pantalla (región) |
| Capturar ventana activa | `Meta + ImpPantalla` | Captura solo la ventana enfocada |
| Administrador de tareas | `Meta + Esc` | Abre System Monitor |
| Cerrar sesión | `Ctrl + Alt + Supr` | Muestra opciones de sesión (apagar, reiniciar...) |
| Escritorio virtual anterior / siguiente | `Meta + Ctrl + ←` / `→` | Alterna entre escritorios virtuales (no confundir con Meta+← que divide la ventana) |
| Cambiar idioma teclado | `Meta + Alt + K` | Alterna entre distribuciones de teclado (en tu config es Meta+Alt+K) |
| Historial del portapapeles | `Meta + V` | Muestra el historial de elementos copiados |
| Selector de Emojis | `Meta + .` | Abre el selector nativo de emojis de Plasma |

## Comandos básicos de terminal

| Comando | Qué hace |
| --- | --- |
| `ls` | Lista los archivos de la carpeta actual |
| `ls -la` | Lista todo, incluidos archivos ocultos, con detalles |
| `cd carpeta` | Entra a una carpeta |
| `cd ..` | Sube a la carpeta anterior |
| `mkdir nombre` | Crea una nueva carpeta |
| `touch archivo` | Crea un archivo vacío |
| `cp origen destino` | Copia un archivo |
| `mv origen destino` | Mueve o renombra |
| `rm archivo` | Elimina un archivo (¡cuidado!) |
| `pwd` | Muestra la carpeta donde estás |
| `code .` | Abre VS Code en la carpeta actual **[VS Code]** |
| `sudo pacman -S paquete` | Instala un paquete en Arch |
| `ctrl + c` | Cancela el comando actual en la terminal |
