⌨️ Script Meta+C — Abrir VS Code

Cómo está montado y por qué funciona · Documentación personal

Atajos Script Meta+C (VS Code)

Qué hace

Con Meta + C se abre Visual Studio Code. La parte interesante: si tienes Dolphin (gestor de archivos) enfocado, VS Code se abre directamente con la carpeta que estás viendo como proyecto. Si no hay Dolphin enfocado, abre VS Code normal (sin argumentos).

💡 Truco del que depende: Dolphin debe tener activada la opción "Mostrar la ruta completa en la barra de título" (ShowFullPathInTitlebar=true). Así el título de la ventana de Dolphin es la ruta de la carpeta, y el script solo tiene que leerla.

Archivos que intervienen

  1. El script (el corazón de todo): ~/.local/bin/open-code
  2. El lanzador .desktop (para que KDE lo vea como aplicación y le puedas dar atajo): ~/.local/share/applications/net.local.open-code.desktop
  3. El atajo global (la línea que ata Meta+C al lanzador): ~/.config/kglobalshortcutsrc → sección [services][net.local.open-code.desktop] → _launch=Meta+C

Cómo se hace paso a paso

  1. Crear el script con el contenido de abajo y darle permisos de ejecución: 
    mkdir -p ~/.local/bin
nano ~/.local/bin/open-code
chmod +x ~/.local/bin/open-code
  2. Activar la ruta completa en Dolphin (una sola vez): 
    kwriteconfig6 --file dolphinrc --group General --key ShowFullPathInTitlebar true
    O desde la GUI: Preferencias → Configurar Dolphin → General → "Mostrar la ruta completa en la barra de título".
  3. Crear el lanzador .desktop con el contenido de abajo.
  4. Asignar el atajo (la parte que hace que Meta+C funcione).
    Desde la GUI: Configuración del sistema → Atajos → Atajos globales, busca la app VsCode y ponle Meta + C.
    O por línea de comandos: 
    kwriteconfig6 --file kglobalshortcutsrc --group "services" --group "net.local.open-code.desktop" --key "_launch" "Meta+C"
  5. Reiniciar la sesión o recargar atajos para que los cambios surtan efecto: 
    kquitapp6 kglobalaccel && kstart kglobalaccel

El código del script (open-code)

Guardado en ~/.local/bin/open-code:

#!/usr/bin/env bash
#
# open-code — abre Visual Studio Code con la carpeta activa de Dolphin
#
# Vincula este script a Super + C en:
#   KDE System Settings → Shortcuts → Custom Shortcuts
#   Trigger: Meta + C
#   Action:  /home/emerson/.local/bin/open-code
#
# Comportamiento:
#   - Dolphin enfocado → code "/ruta/de/la/carpeta"
#   - Otra aplicación   → code (sin argumentos)
#
# Requisito único (una sola vez):
#   Activar "ShowFullPathInTitlebar=true" en Dolphin para que el título
#   de la ventana contenga la ruta completa en lugar de solo el nombre.
#
#   Para activarlo:
#     kwriteconfig6 --file dolphinrc --group General --key ShowFullPathInTitlebar true
#
#   O desde la GUI: Preferencias → Configurar Dolphin → General →
#   "Mostrar la ruta completa en la barra de título"
#
# Dependencias:
#   - qdbus6 (qt6-tools, ya instalado en Plasma 6)
#

#=============================================================================
# Funciones
#=============================================================================

# Descubre dinámicamente los objetos D-Bus de Dolphin bajo un servicio.
# No asume la existencia de /dolphin/Dolphin_1; lista los que realmente hay.
# Parámetros: $1 = nombre del servicio D-Bus (org.kde.dolphin-*)
# Salida: lista de rutas (una por línea), ej: /dolphin/Dolphin_1 /dolphin/Dolphin_2
discover_dolphin_views() {
    local service="$1"
    qdbus6 "$service" 2>/dev/null \
        | grep -E "^/dolphin/Dolphin_[0-9]+$"
}

# Busca la ventana de Dolphin que tiene el foco entre todas las instancias.
# Establece las variables globales DOLPHIN_SERVICE y DOLPHIN_VIEW.
# Retorna 0 si encontró una, 1 si no.
find_active_dolphin() {
    DOLPHIN_SERVICE=""
    DOLPHIN_VIEW=""

    local svc view active
    while IFS= read -r svc; do
        svc="${svc#"${svc%%[! ]*}"}"
        svc="${svc%"${svc##*[! ]}"}"
        [ -z "$svc" ] && continue

        for view in $(discover_dolphin_views "$svc"); do
            active=$(qdbus6 "$svc" "$view" \
                org.kde.dolphin.MainWindow.isActiveWindow 2>/dev/null)
            if [ "$active" = "true" ]; then
                DOLPHIN_SERVICE="$svc"
                DOLPHIN_VIEW="$view"
                return 0
            fi
        done
    done < <(qdbus6 | grep "org.kde.dolphin-")

    return 1
}

# Lee la ruta completa desde el título de la ventana de Dolphin.
# Requiere ShowFullPathInTitlebar=true en la configuración de Dolphin.
# Parámetros: $1 = servicio D-Bus, $2 = ruta del objeto vista
# Salida: imprime la ruta absoluta (ej: /home/usuario/proyecto)
get_dolphin_path() {
    local service="$1"
    local view="$2"

    local title
    title=$(qdbus6 "$service" "$view" \
        org.qtproject.Qt.QWidget.windowTitle 2>/dev/null)

    # El título con ShowFullPathInTitlebar=true es la ruta literal.
    # Verificamos que comience con "/" (ruta absoluta) y que exista.
    if [[ "$title" == /* ]] && [ -d "$title" ]; then
        printf "%s" "$title"
        return 0
    fi

    return 1
}

# Abre VS Code. Si recibe una ruta válida, la abre como proyecto.
# Parámetros: $1 = ruta a la carpeta (opcional)
open_vscode() {
    if [ -n "$1" ]; then
        exec code "$1"
    else
        exec code
    fi
}

#=============================================================================
# Ejecución principal
#=============================================================================

main() {
    local folder=""

    # 1. Detectar si Dolphin está enfocado y cuál es la ventana activa
    find_active_dolphin

    if [ -n "$DOLPHIN_SERVICE" ] && [ -n "$DOLPHIN_VIEW" ]; then
        # 2. Leer la ruta directamente del título de la ventana
        folder=$(get_dolphin_path "$DOLPHIN_SERVICE" "$DOLPHIN_VIEW")
    fi

    # 3. Abrir VS Code con la ruta obtenida, o sin argumentos si no hay ruta
    open_vscode "$folder"
}

# Solo ejecutar cuando el script se invoca directamente (no al hacer source)
if [ "${BASH_SOURCE[0]}" = "$0" ]; then
    main "$@"
fi

El lanzador .desktop

Guardado en ~/.local/share/applications/net.local.open-code.desktop:

[Desktop Entry]
Exec=/home/emerson/.local/bin/open-code
Name=VsCode
NoDisplay=true
StartupNotify=false
Type=Application
X-KDE-GlobalAccel-CommandShortcut=true
💡 Nota: X-KDE-GlobalAccel-CommandShortcut=true le dice a KDE que esta app soporta un atajo global. NoDisplay=true hace que no aparezca en el menú de inicio, solo en la lista de aplicaciones con atajo global.

Por qué funciona así

  • KDE guarda todos los atajos globales en ~/.config/kglobalshortcutsrc. El formato de cada línea es acción=activo,por_defecto,nombre.
  • La línea clave que ata todo es: 
    [services][net.local.open-code.desktop]
_launch=Meta+C
  • Meta+C ejecuta el Exec del .desktop, que invoca open-code, que a su vez consulta D-Bus para saber si Dolphin está enfocado y lee la ruta desde el título de la ventana.
  • Es un atajo de "Servicio de aplicación" (services) y no de "Atajos personalizados" (khotkeys), por eso se configura con _launch.

Solución de problemas

SíntomaPor qué / qué revisar
Meta+C no hace nada La tecla Meta puede estar desactivada por firmware (Fn+Meta). O el atajo global se perdió: revisa la línea _launch=Meta+C en kglobalshortcutsrc.
Abre VS Code pero sin el proyecto Dolphin no está enfocado, o falta ShowFullPathInTitlebar=true en dolphinrc. Verifícalo con kwriteconfig6 --file dolphinrc --group General --key ShowFullPathInTitlebar.
El título de Dolphin no es la ruta Reinicia Dolphin tras cambiar la opción de la barra de título (o cierra y abre todas sus ventanas).
qdbus6 no existe Instala qt6-tools: sudo pacman -S qt6-tools.
